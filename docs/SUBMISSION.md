# FAMILIAR — submission-ready content (draft; verify device status before submitting)

**Project name:** FAMILIAR

**Team tagline:** Looks Familiar. Sounds Familiar. Feels Familiar.

**Suggested track (team must choose):** Natural Interaction / Track 03 — glanceable contextual interface; the official event theme is Second Nature.

## 1-sentence pitch

FAMILIAR explores a lightweight, glanceable cue interface for smart glasses, starting with a **simulated** proximity-and-attention scenario and extending toward voluntary visual memories, sound memories, and social prompts.

## What exists in the repository

- Browser demo: manually select an example context, phone-attention flag, and **simulated** distance.
- Deterministic idle/caution/warning outputs and optional **browser** tone.
- Four reproducible presets and a green HUD browser preview.
- Conversation Starter and Social Navigator manual browser prototypes.
- Hardware-neutral JSON message shape for future SDK translation (not an SDK call).
- Automated logic and preview-contract tests.

## What does NOT exist without further verification

- On-glasses UI; camera streaming/recognition; proximity sensor; phone-use recognition; glasses audio; reliable hazard detection.
- These must NOT be claimed in a submission until tested and documented on the actual unit.

## Demo script (40–60 seconds)

1. 'This is FAMILIAR, for small helpful cues that feel like second nature.'
2. 'Our browser demo uses manually staged inputs, not real hazard sensors.'
3. Tap **1 · Idle**, **2 · Caution**, **3 · Warning** to show a glanceable progression.
4. 'The UI shows a small green message; the tone is generated in the browser if enabled.'
5. 'We want to translate these short cues to the exact glasses SDK. We only call that hardware integration done after a real Hello World and observed output.'
6. 'Our roadmap adds opt-in visual recall, sound recall and voluntary conversation reminders, with consent by design.'
